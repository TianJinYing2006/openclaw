# 会话上下文跨线程丢失 - 解决方案

## 问题根源

```
ILinkBotService (主线程)
    ↓ 调用 replyService.createReply(message, items, status())
ILinkReplyService (主线程)
    ↓ 调用 aiChatService.answerWithContextToken(userId, contextToken, prompt, images)
AiChatService (主线程)
    ↓ 调用 gateway.generate(userId, contextToken, history, prompt, images, files, budget)
SpringAiChatCompletionsGateway (主线程)
    ↓ 调用 artifacts.begin(userId, contextToken)  ← 设置 ThreadLocal
ToolArtifactCollector (ThreadLocal 存储)
    ↓
ScheduleTools.createSchedule()
    ↓ 调用 artifacts.contextToken()  ← 读取 ThreadLocal
    ↓ 返回 null  ← 线程切换导致数据丢失
```

**问题**：`ILinkBotService` 使用线程池处理消息，`ToolArtifactCollector` 使用 `ThreadLocal` 存储数据，当线程切换时，`ThreadLocal` 数据丢失。

---

## 解决方案：显式传递上下文

### 核心思路

1. **在 `ScheduledTaskManager` 中保存每个用户的 `contextToken`**
2. **在 `ScheduleTools` 中显式传递 `contextToken` 给 `ScheduledTaskManager`**
3. **当任务触发时，从 `ScheduledTaskManager` 中获取 `contextToken`**

### 调用链

```
ILinkReplyService.createReply(message, items, status)
    ↓ message.contextToken()  ← 获取 contextToken
    ↓
AiChatService.answerWithContextToken(userId, contextToken, prompt, images)
    ↓
SpringAiChatCompletionsGateway.generate(userId, contextToken, history, prompt, budget)
    ↓
ScheduleTools.createSchedule(title, content, schedule)
    ↓ 从 ToolArtifactCollector 获取 userId
    ↓ 从 ScheduledTaskManager 获取 contextToken  ← 新增
    ↓
ScheduledTaskManager.saveContextToken(userId, contextToken)  ← 保存
    ↓
ScheduledTaskManager.scheduleTask(task)
    ↓ 使用保存的 contextToken 发送消息
```

## 修改的文件

### 1. ScheduledTaskManager.java

**变更**：添加 `contextToken` 缓存

```java
@Component
public class ScheduledTaskManager {
    
    // 缓存每个用户的 contextToken
    private final Map<String, String> userContextTokens = new ConcurrentHashMap<>();
    
    /**
     * 保存用户的 contextToken
     */
    public void saveContextToken(String userId, String contextToken) {
        if (userId != null && contextToken != null) {
            userContextTokens.put(userId, contextToken);
            log.info("Saved contextToken for user {}", userId);
        }
    }
    
    /**
     * 获取用户的 contextToken
     */
    public String getContextToken(String userId) {
        return userContextTokens.get(userId);
    }
    
    /**
     * 触发提醒消息
     */
    private void triggerReminder(ScheduledTask task) {
        String userId = task.getUserId();
        String contextToken = getContextToken(userId);  // 从缓存获取
        
        if (contextToken == null) {
            contextToken = task.getContextToken();  // 从数据库获取
        }
        
        if (contextToken == null) {
            log.warn("No contextToken for user {}", userId);
            return;
        }
        
        // 发送消息
        ilinkBotService.sendText(userId, contextToken, buildReminderMessage(task));
    }
}
```

### 2. ScheduleTools.java

**变更**：调用 `ScheduledTaskManager.saveContextToken()` 保存 `contextToken`

```java
@Tool(name = "create_schedule")
public String createSchedule(String title, String content, String schedule) {
    String userId = artifacts.userId();
    String contextToken = artifacts.contextToken();
    
    if (contextToken == null || contextToken.isBlank()) {
        return "无法获取会话上下文，请重新发起对话";
    }
    
    // 保存 contextToken 到 ScheduledTaskManager
    taskManager.saveContextToken(userId, contextToken);
    
    // 创建任务
    ScheduledTask task = scheduleService.createTask(userId, contextToken, title, content, ...);
    
    // 调度任务
    taskManager.scheduleTask(task);
    
    return "已创建定时任务...";
}
```

### 3. ScheduledTask.java

**变更**：保留 `contextToken` 字段（用于重启恢复）

```java
@Data
@TableName("scheduled_task")
public class ScheduledTask {
    // ... 其他字段
    
    @TableField("context_token")
    private String contextToken;  // 保存到数据库，用于重启恢复
}
```

## 工作流程

### 1. 创建定时任务时

```
用户: 两分钟后提醒我喝水
    ↓
ILinkReplyService.createReply(message, items, status)
    ↓ message.contextToken() = "xxx"
    ↓
AiChatService.answerWithContextToken(userId, contextToken, prompt, images)
    ↓
SpringAiChatCompletionsGateway.generate(userId, contextToken, history, prompt, budget)
    ↓
ScheduleTools.createSchedule(title, content, schedule)
    ↓ artifacts.contextToken() = "xxx"
    ↓ taskManager.saveContextToken(userId, "xxx")  ← 保存到内存
    ↓ scheduleService.createTask(userId, "xxx", ...)  ← 保存到数据库
    ↓ taskManager.scheduleTask(task)
```

### 2. 定时任务触发时

```
ScheduledTaskManager.executeTask(task)
    ↓
triggerReminder(task)
    ↓ getContextToken(userId) = "xxx"  ← 从内存获取
    ↓ ilinkBotService.sendText(userId, "xxx", message)
```

### 3. 应用重启时

```
ScheduledTaskManager.init()
    ↓
loadAndScheduleAllTasks()
    ↓ 从数据库加载任务（包含 contextToken）
    ↓ scheduleTask(task)
    ↓ 任务触发时使用 task.getContextToken()
```

---

## 优势

1. **不依赖 ThreadLocal**：显式传递，不依赖线程模型
2. **支持重启恢复**：`contextToken` 保存到数据库
3. **代码清晰**：调用链明确，易于调试
4. **向后兼容**：如果内存中没有 `contextToken`，从数据库获取

---

## 验证方式

1. 创建定时任务，检查 `contextToken` 是否保存到内存和数据库
2. 等待任务触发，检查是否成功发送消息
3. 重启应用，检查任务是否能正常触发
