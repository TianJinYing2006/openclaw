# 高德工具功能问题诊断与修复计划

## 问题描述

用户发送"从杭州东站到西湖怎么走"，机器人回复"暂时没有生成有效回答"。

**重要发现**：本地项目能正常工作，推送到远程后拉取到本地就不能工作。

## 问题根因

### 已确认的根本原因

**`secret.properties` 文件被 `.gitignore` 忽略，不会推送到远程仓库！**

验证过程：
1. 检查 `.gitignore` 文件，第 25 行：`secret.properties`
2. 运行 `git ls-files --error-unmatch src/main/resources/secret.properties` 返回错误，确认文件未被 Git 追踪
3. `AmapService` 使用 `@Value("${amap.api-key:not-configured}")` 注入 API Key
4. 当 `secret.properties` 不存在时，使用默认值 `not-configured`

### 问题链路

```
本地有 secret.properties → 包含高德 API Key → 高德工具正常工作
    ↓ 推送到远程
secret.properties 被 .gitignore 忽略 → 远程仓库没有此文件
    ↓ 拉取到新环境
新环境没有 secret.properties → API Key 使用默认值 "not-configured" → 高德 API 调用失败
```

### 相关文件

| 文件 | 作用 | 是否被 Git 追踪 |
|------|------|-----------------|
| `.gitignore` | 忽略 secret.properties | 是 |
| `src/main/resources/secret.properties` | 存储高德 API Key | **否** |
| `src/main/java/.../AmapService.java` | 使用 @Value 注入 API Key | 是 |

### 验证命令

```bash
# 检查 secret.properties 是否被 Git 追踪
git ls-files --error-unmatch src/main/resources/secret.properties

# 检查 .gitignore 中的配置
cat .gitignore | grep secret

# 检查 AmapService 中的默认值配置
grep -n "not-configured" src/main/java/com/example/ykdsummer/navigation/AmapService.java
```

## 解决方案

### 方案A：手动复制 secret.properties（推荐，最简单）

1. 从原始开发环境复制 `secret.properties` 文件到新环境的 `src/main/resources/` 目录
2. 确保 API Key 正确

### 方案B：使用环境变量（推荐，更安全）

不使用 `secret.properties`，改用环境变量注入：

```powershell
# Windows PowerShell
$env:AMAP_API_KEY="fb9f1a22c7f5eda72058cf39a23f46f2"
mvn spring-boot:run "-Dspring-boot.run.arguments=--ilink.enabled=true"

# 或者在 IDEA 运行配置中设置环境变量
```

### 方案C：修改配置加载方式

修改 `application.properties`，添加高德 API Key 的环境变量支持：

```properties
amap.api-key=${AMAP_API_KEY:not-configured}
```

然后在 `secret.properties` 中保留默认值（或在环境变量中设置）。

### 方案D：创建 example 配置文件

1. 创建 `secret.properties.example` 文件，包含占位符
2. 开发者从 example 文件复制并填入真实密钥
3. 确保 `.gitignore` 只忽略 `secret.properties`，不忽略 `secret.properties.example`

## 额外说明

同样的问题可能影响其他 API Key：
- `AI_API_KEY` - MiMo/OpenAI API Key
- `DASHSCOPE_API_KEY` - 阿里云 DashScope API Key
- `TENCENTCLOUD_SECRET_ID` - 腾讯云 SecretId
- `TENCENTCLOUD_SECRET_KEY` - 腾讯云 SecretKey

建议统一使用环境变量管理所有敏感配置，而不是依赖 `secret.properties` 文件。
