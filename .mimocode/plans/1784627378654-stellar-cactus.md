# 问题诊断与解决方案

## 问题分析

用户运行 Spring Boot 应用后没有弹出二维码，日志显示：
```
iLink is disabled. Set ILINK_ENABLED=true to start QR login.
```

## 根因

**这不是分支问题，而是配置问题。**

在 `application.properties` 第 14 行：
```properties
ilink.enabled=${ILINK_ENABLED:false}
```

`ilink.enabled` 默认值为 `false`，必须通过以下方式之一启用：
1. 环境变量：`ILINK_ENABLED=true`
2. 启动参数：`--ilink.enabled=true`

## 分支对比

| 分支 | 状态 | 说明 |
|------|------|------|
| `lwb` (当前) | ✅ 有完整 application.properties | 从 master 复制，包含所有配置 |
| `ilink-lwb` | ❌ 没有 application.properties | 这是一个完全不同的项目 (com.youkeda.exercise.shared) |

**结论：`ilink-lwb` 分支不是正确的分支**，它是一个独立的练习项目，与当前的 ykd-summer 项目无关。

## 解决方案

在 IDEA 运行配置中添加启动参数：

1. 打开 IDEA → Run → Edit Configurations
2. 找到 YkdSummerApplication 的运行配置
3. 在 **VM options** 或 **Program arguments** 中添加：
   ```
   --ilink.enabled=true
   ```
4. 同时确保设置了 AI 密钥环境变量：
   ```
   AI_API_KEY=你的密钥
   AI_IMAGE_API_KEY=你的图片生成密钥
   ```
5. 重新启动应用

## 验证

启动后日志应该显示：
```
iLink long polling started
```

而不是：
```
iLink is disabled. Set ILINK_ENABLED=true to start QR login.
```
