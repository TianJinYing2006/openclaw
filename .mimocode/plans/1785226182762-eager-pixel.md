# 定时任务无法获取 contextToken 的根本原因与修复计划

## 问题根因

### 核心发现：contextToken 在 `FileInstructionService.process()` 链路中丢失

`ILinkReplyService.createReply()` 对纯文本消息有两条代码路径：

```
用户发送 "设置喝水提醒" (纯文本)
  → extract(items) → isPlainTextOnly() = true
  → 路径 A (line 176): fileInstructionService.process(userId, prompt, sourceFile)
    → aiChatService.answerWithInternalPromptRich(userId, prompt, modelPrompt, files)
    → answerInternal(userId, ...) → gateway.generate(userId, history, prompt, images, files, budget)
    → artifacts.begin(userId) ← contextToken 丢失！
```

对比正确路径：
```
用户发送图片+文字
  → isPlainTextOnly() = false, hasImage() = true
  → 路径 B (line 195): aiChatService.answerWithContextTokenRich(userId, contextToken, ...)
    → answerInternalWithContextToken(userId, contextToken, ...)
    → gateway.generate(userId, contextToken, history, ...)
    → artifacts.begin(userId, contextToken) ← contextToken 正确传递
```

**根本原因**：`FileInstructionService.process()` 方法没有接收和传递 contextToken 参数。

### 调用链追踪

| 层级 | 文件 | 方法 | contextToken |
|------|------|------|-------------|
| 1 | ILinkReplyService:176 | `fileInstructionService.process(userId, prompt, sourceFile)` | ❌ 未传入 |
| 2 | FileInstructionService:86 | `aiChatService.answerWithInternalPromptRich(userId, ...)` | ❌ 未传入 |
| 3 | AiChatService:130 | `answerInternal(userId, ...)` | ❌ 未传入 |
| 4 | AiChatService:290 | `gateway.generate(userId, history, prompt, images, files, budget)` | ❌ 未传入 |
| 5 | SpringAiChatCompletionsGateway:278 | `artifacts.begin(userId)` | ❌ 只有 userId |
| 6 | ScheduleTools:76 | `artifacts.contextToken()` | → null |

## 修复方案

### 修改 1：`FileInstructionService.java` — 添加 contextToken 参数

**文件**: `src/main/java/com/example/ykdsummer/bot/file/FileInstructionService.java`

```java
// 修改 process 方法签名，添加 contextToken 参数
public Result process(String userId, String contextToken, String instruction, AiFile sourceFile) {
    // ... 现有逻辑 ...
    AiChatService.AssistantAnswer answer = aiChatService.answerWithContextTokenRich(
            userId, contextToken, safeInstruction, input.modelPrompt(), input.files());
    // ...
}
```

### 修改 2：`ILinkReplyService.java` — 传递 contextToken（2 处调用）

**文件**: `src/main/java/com/example/ykdsummer/bot/service/ILinkReplyService.java`

**调用 1 (line 135)** — 文件+文字场景：
```java
return toReply(fileInstructionService.process(
        message.fromUserId(), message.contextToken(), content.prompt(), file));
```

**调用 2 (line 178)** — 纯文本场景：
```java
return toReply(fileInstructionService.process(
        message.fromUserId(), message.contextToken(), content.prompt(), sourceFile));
```

### 无需修改 `AiChatService.java`

已有 `answerWithContextTokenRich(userId, contextToken, userPrompt, modelPrompt, files)` 方法（line 149），`FileInstructionService` 直接调用即可。

### 修改 4：测试文件更新

**文件**: `src/test/java/com/example/ykdsummer/bot/service/ILinkReplyServiceTest.java`

更新 `FileInstructionService.process()` 的 mock 调用，添加 contextToken 参数。

### 修改 4：测试文件更新

**文件**: `src/test/java/com/example/ykdsummer/bot/service/ILinkReplyServiceTest.java`

更新 5 处 `fileInstructionService.process()` 的 mock 调用，添加 contextToken 参数（"context"）：

```java
// 例如：
when(fileInstructionService.process("user", "context", "第一段\n第二段", null))
```

## 验证方式

1. 启动应用，发送 "设置一个喝水提醒，每小时提醒我"
2. 检查日志中 `ScheduleTools` 是否正确获取到 contextToken（应为非 null）
3. 检查 `scheduled_task` 表的 `context_token` 字段是否有值
4. 等待定时任务触发，验证消息是否成功发送
