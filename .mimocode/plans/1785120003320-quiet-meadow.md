# 会话持久化实施方案

## 项目现状

- Spring Boot 3.5.16 + Java 21
- 已有 `sqlite-jdbc`、`spring-boot-starter-jdbc`、`mybatis-plus-spring-boot3-starter`、`lombok` 依赖
- 数据库文件路径：`data/wechat/wechat.db`
- 当前会话存储：Caffeine 内存缓存（`AiChatService.conversations`）
- 现有 `chat` 包有基础 CRUD 代码，需要迁移到 `wechat` 包

## 消息流分析

```
ILinkBotService.handleInboundMessage(message)
  └─ processReply(message, items)
      └─ ILinkReplyService.createReply(message, items, status)
          └─ aiChatService.answer(userId, prompt, images)
              └─ AiChatService.answerInternal(...)
                  ├─ history = conversation.copyMessages()  ← 从 Caffeine 内存读取
                  ├─ gateway.generate(userId, history, prompt, ...)
                  ├─ conversation.remember(USER, memoryText)  ← 存入 Caffeine
                  └─ conversation.remember(ASSISTANT, reply.text())  ← 存入 Caffeine
```

## 改造目标

1. 以微信 `userId` 作为 `session_id`
2. 用户消息、AI回复分别持久化到 `chat_message` 表
3. 自动维护 `chat_session` 记录（不存在则创建）
4. AI 对话前从数据库加载历史记录作为上下文
5. 代码放置在 `com.example.ykdsummer.wechat`
6. 表结构保持现有设计不变

## 表结构（保持不变）

**chat_session 表**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| session_id | VARCHAR(64) | 业务会话ID（=微信userId），唯一 |
| user_id | VARCHAR(64) | 用户ID |
| title | VARCHAR(255) | 会话标题 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**chat_message 表**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键自增 |
| session_id | VARCHAR(64) | 关联会话ID（=微信userId） |
| role | VARCHAR(20) | 消息角色（user/assistant） |
| content | TEXT | 消息内容 |
| created_at | DATETIME | 创建时间 |

### 第四步：修改 AiChatService 集成数据库持久化

**修改文件**：`src/main/java/com/example/ykdsummer/ai/service/AiChatService.java`

#### 改动点 1：添加 import

```java
import com.example.ykdsummer.wechat.entity.ChatMessage;

```

#### 改动点 2：添加字段注入

在类中添加两个字段：
```java
private final ChatSessionService chatSessionService;
private final ChatMessageService chatMessageService;
```

#### 改动点 3：修改所有构造函数

在每个构造函数中初始化这两个新字段（使用 `@Autowired(required=false)` 或在有参构造中注入）。

#### 改动点 4：修改 answerInternal 方法（第 125-196 行）

在 `synchronized (conversation)` 块内，`conversation.copyMessages()` 之后添加：

```java
// 确保会话存在
chatSessionService.ensureSession(userId);

// 从数据库加载历史记录（替代纯内存历史）
List<ChatMessage> dbHistory = chatMessageService.getLatestMessages(userId, properties.getMaxMemoryMessages());
List<ConversationMessage> history = dbHistory.stream()
    .map(msg -> new ConversationMessage(
        ConversationMessage.Role.valueOf(msg.getRole().toUpperCase()),
        msg.getContent()))
    .toList();
```

在 `gateway.generate()` 成功返回后，`conversation.remember()` 之后添加：

```java
// 持久化用户消息
chatMessageService.saveMessage(userId, "user", memoryText(memoryPrompt, images, files));

// 持久化 AI 回复
chatMessageService.saveMessage(userId, "assistant", reply.text());
```

#### 改动点 5：修改 clear 方法（第 198-207 行）

在清空内存缓存之前添加数据库清理：

```java
// 清空数据库记录
chatMessageService.deleteBySessionId(userId);
```

## SQLite 语法适配要点

1. **自增主键**：`INTEGER PRIMARY KEY AUTOINCREMENT`，MyBatis-Plus 配置 `IdType.AUTO`
2. **时间函数**：默认值使用 `datetime('now','localtime')` 而非 `NOW()`
3. **分页**：`LIMIT size OFFSET offset`，MyBatis-Plus 分页插件已处理
4. **连接池**：`maximum-pool-size=1`，SQLite 不支持并发写入
5. **索引**：`CREATE INDEX IF NOT EXISTS` 避免重复创建报错
