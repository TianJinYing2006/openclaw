# 文档生成功能计划

## 需求
用户通过命令触发，让 AI 生成文档内容，然后导出为 Word/PDF 文件发送给用户。

## 触发方式
```
/生成文档 项目周报          → 生成 Word 文档
/生成文档pdf 项目周报       → 生成 PDF 文档
```
AI 根据标题自动构思内容并生成文档。

## 技术方案

### 新建文件
- `DocumentGenerator.java` — 文档生成服务
  - `byte[] generateDocx(String title, String content)` — 生成 Word
  - `byte[] generatePdf(String title, String content)` — 生成 PDF

### 修改文件
- `MessageDispatcher.java` — 添加 `/生成文档` 和 `/生成文档pdf` 命令

### 依赖（已有）
- `poi-ooxml` — Word 生成
- `pdfbox` — PDF 生成

## 实现步骤

### 1. 新建 `DocumentGenerator.java`

```java
public class DocumentGenerator {

    // 生成 Word 文档
    public static byte[] generateDocx(String title, String content) {
        XWPFDocument doc = new XWPFDocument();
        // 添加标题
        XWPFParagraph titlePara = doc.createParagraph();
        titlePara.setAlignment(ParagraphAlignment.CENTER);
        XWPFRun titleRun = titlePara.createRun();
        titleRun.setText(title);
        titleRun.setBold(true);
        titleRun.setFontSize(18);
        // 添加正文（按段落分割）
        for (String line : content.split("\n")) {
            XWPFParagraph para = doc.createParagraph();
            XWPFRun run = para.createRun();
            run.setText(line);
            run.setFontSize(12);
        }
        // 转为 byte[]
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        doc.write(bos);
        doc.close();
        return bos.toByteArray();
    }

    // 生成 PDF 文档
    public static byte[] generatePdf(String title, String content) {
        PDDocument doc = new PDDocument();
        PDPage page = new PDPage();
        doc.addPage(page);
        // 使用 PDPageContentStream 写入文本
        // ...
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        doc.save(bos);
        doc.close();
        return bos.toByteArray();
    }
}
```

### 2. 修改 `MessageDispatcher.java`

在 `handleTextMessage()` 中添加命令处理：

```java
if (text.startsWith("/生成文档")) {
    handleGenerateDocument(message, userId, text, false);
    return;
}
if (text.startsWith("/生成文档pdf")) {
    handleGenerateDocument(message, userId, text, true);
    return;
}
```

新增 `handleGenerateDocument()` 方法：
1. 提取标题（去掉命令前缀）
2. 调用 AI 生成内容：`aiService.chat("请根据以下主题生成一份完整的文档内容：\n" + title)`
3. 调用 `DocumentGenerator.generateDocx()` 或 `generatePdf()` 生成文件
4. `bot.sendFile(userId, contextToken, fileName, fileBytes)` 发送给用户

### 代码流程
```
用户发送: /生成文档 项目周报
  → handleGenerateDocument()
  → aiService.chat("请根据以下主题生成一份完整的文档内容：\n项目周报")
  → AI 返回文档内容文本
  → DocumentGenerator.generateDocx("项目周报", aiContent)
  → bot.sendFile(userId, contextToken, "项目周报.docx", docxBytes)
  → 用户收到 Word 文件
```
