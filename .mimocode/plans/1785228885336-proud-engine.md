# contextToken 路径问题调查报告

## 结论

**contextToken 保存路径没有问题**——contextToken 不是通过文件系统存储的，而是通过内存 Map + SQLite 数据库双层存储。

## 根因分析

定时任务无法获取上下文内容的最可能原因是：

1. **contextToken 过期/失效**：微信的 contextToken 是会话级别的令牌，可能随时间失效
2. **应用重启后内存缓存丢失**：`savedMessages` 和 `userContextTokens` 全部清空，只能回退到数据库中的旧 token
3. **静默失败**：contextToken 为空或失效时仅记录 warn 日志，不抛异常

## 关键文件

- `src/main/java/com/example/ykdsummer/schedule/service/ScheduledTaskManager.java` - 核心调度逻辑
- `src/main/java/com/example/ykdsummer/schedule/service/ScheduleService.java` - 数据库操作
- `src/main/java/com/example/ykdsummer/bot/service/ILinkReplyService.java` - token 保存触发点
- `src/main/java/com/example/ykdsummer/config/SqliteInitializer.java` - 数据库 schema

## 建议排查

检查应用日志中 `ScheduledTaskManager` 输出的 warn 级别日志，确认具体失败原因。
