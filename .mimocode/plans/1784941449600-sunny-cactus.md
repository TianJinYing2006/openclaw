## 4. 6 层架构

```
微信消息
  │
  ├─ [接入层]  ILinkBotService         — SDK 长轮询 + 去重 + 限流 + 线程池
  ├─ [路由层]  ILinkReplyService        — 消息类型分流（文件/命令/语音/视频/文字/图片）
  ├─ [编排层]  AgentCoordinator         — 工作区管理 + ThreadLocal 上下文 + 结果分发
  ├─ [会话层]  AiChatService            — Caffeine 多轮记忆 + synchronized 顺序保证
  ├─ [网关层]  RoutingLlmGateway        — 路由文本到 Chat Completions / 多模态到 Responses
  │           SpringAiChatCompletionsGateway — Spring AI Function Calling + Tools
  └─ [工具层]  ai/tool/*               — 40+ @Tool 方法，LLM 按需调用
```

---

## 5. 核心类详解

### 5.1 网关层
- **`RoutingLlmGateway`** (`@Primary`): 根据是否含图片/文件，路由到 Chat Completions 或 Responses 协议
- **`SpringAiChatCompletionsGateway`**: 注册所有 Tool Callback，调用 ChatClient
- **`OpenAiResponsesGateway`**: 多模态（图片/文件/视频帧）处理
- **`TracingToolCallback`**: 装饰器，添加 trace 日志 + 实时证据增强

### 5.2 会话层
- **`AiChatService`**: Caffeine 缓存每用户多轮对话历史，synchronized 保证顺序，Token 预算保护
- **`AiUsageMeter`**: 内存级每日 Token 计量器

### 5.3 编排层
- **`ToolRegistry`**: 启动时扫描所有 @Tool Bean，提供 `find(name)` / `allToolBeans()`
- **`AgentContext`**: 单次 Agent 执行上下文（userId, sessionId, 文件路径, 迭代计数）
- **`AgentSessionContext`**: ThreadLocal 请求级上下文

### 5.4 接入层
- **`ILinkBotService`**: 核心机器人服务，管理 iLink SDK 生命周期，8 分区文本线程池 + 图片/视频专用线程池，去重，限流
- **`ILinkReplyService`**: 消息路由器，解析 SDK item 提取内容，路由到命令/AI/视频/文件处理

## 7. 关键配置

### application.properties (168 行)
- **模型**: `mimo-v2.5` via `api.xiaomimimo.com`
- **图片生成**: `wan2.7-image-pro`，1024x1024，high quality
- **iLink**: 微信 iLink 协议 SDK
- **TTS**: 阿里云 DashScope CosyVoice（默认 `longanyang` 音色）
- **ASR**: 腾讯云语音识别（`16k_zh` 引擎）
- **OSS**: 阿里云 OSS 图片存储
- **视频**: FFmpeg 抽帧，最大 20MB/60s，10 帧

### pom.xml 关键依赖
- Spring Boot 3.5.16 + Spring AI 1.1.8
- `weixin-ilink-sdk` — 微信协议
- `openai-java` 4.43.0 — OpenAI Responses API
- `tencentcloud-sdk-java-asr` — 语音识别
- `aliyun-sdk-oss` — 云存储
- `x-easypdf-pdfbox` + `pdfbox` + `poi-ooxml` — 文档处理
- `oapi-sdk` — 飞书 SDK
- `jsoup` — HTML 解析
