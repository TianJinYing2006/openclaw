# 高德路线规划 v3 → v5 升级计划

## 问题背景
当前高德路线规划使用 v3 API，公交模式缺少必填参数 `city`，导致路线规划无法正常工作。用户要求切换到 v5 API（路径规划 2.0）。

## v3 → v5 API 变化总结

| 模式 | v3 端点 | v5 端点 |
|---|---|---|
| 驾车 | `/v3/direction/driving` | `/v5/direction/driving` |
| 步行 | `/v3/direction/walking` | `/v5/direction/walking` |
| 骑行 | `/v3/direction/riding` | `/v5/direction/bicycling`（改名） |
| 公交 | `/v3/direction/transit` | `/v5/direction/transit/integrated` |
| 电动车 | 无 | `/v5/direction/electrobike`（新增） |

### 关键参数变化
- 公交：`city` → `city1`（必填），新增 `city2`（跨城必填）
- 驾车/步行/骑行：duration 等字段需要 `show_fields=cost` 才返回

### 关键返回结构变化
- `info` 值从 `"OK"` 变为 `"ok"`（小写）
- 驾车步骤：`road` → `road_name`，`distance` → `step_distance`
- 公交结果在 `route.transits[]`（不再有 `route.paths[]`）
- 公交 `transits[].duration` 和 `transits[].distance` 直接可用

## 修改文件

### 1. `AmapService.java`
**路径**: `src/main/java/com/example/ykdsummer/navigation/AmapService.java`

修改内容：
- `routePlan()` 方法：URL 从 `/v3/direction/{mode}` 改为 v5 格式
  - driving/walking → `/v5/direction/{mode}`
  - riding → `/v5/direction/bicycling`
  - transit → `/v5/direction/transit/integrated`
- 公交模式添加 `city1` 和 `city2` 查询参数
- 添加 `show_fields=cost` 参数（驾车/步行/骑行需要，获取 duration）
- 添加 API 错误处理和日志（检查 `status` 是否为 `"1"`）

修改内容：

- 更新 `@Tool` description 提示 LLM 在公交规划时提供城市
- 驾车/步行/骑行结果格式调整（duration 现在从 `show_fields=cost` 返回）
- 公交结果展示从 `paths` 改为 `transits`

## 具体实现细节

### AmapService.routePlan() 新签名
```java
public AmapRouteResult routePlan(String origin, String destination, String mode, String destName, String originCity, String destCity)
```

### URL 构建逻辑
```java
String path = switch (mode) {
    case "driving" -> "/v5/direction/driving";
    case "walking" -> "/v5/direction/walking";
    case "riding" -> "/v5/direction/bicycling";
    case "transit" -> "/v5/direction/transit/integrated";
    default -> "/v5/direction/driving";
};
```

### 查询参数
```java
.uri(uriBuilder -> {
    var builder = uriBuilder
        .path(path)
        .queryParam("key", apiKey)
        .queryParam("origin", origin)
        .queryParam("destination", destination);
    // 非公交模式添加 show_fields=cost 获取 duration
    if (!"transit".equals(mode)) {
        builder.queryParam("show_fields", "cost");
    }
    // 公交模式添加城市参数
    if ("transit".equals(mode)) {
        if (originCity != null) builder.queryParam("city1", originCity);
        if (destCity != null) builder.queryParam("city2", destCity);
    }
    return builder.build();
})
```

### AmapRouteResult 更新
```java
public record AmapRouteResult(
    String status,
    String info,
    @JsonProperty("route") Route route,
    String navigationLink
) {
    public record Route(
        @JsonProperty("origin") String origin,
        @JsonProperty("destination") String destination,
        @JsonProperty("paths") List<Path> paths,
        @JsonProperty("transits") List<Transit> transits
    ) {
        public String distance() {
            if (transits != null && !transits.isEmpty()) {
                return transits.get(0).distance();
            }
            return paths != null && !paths.isEmpty() ? paths.get(0).distance() : "未知";
        }
        public String duration() {
            if (transits != null && !transits.isEmpty()) {
                return transits.get(0).duration();
            }
            return paths != null && !paths.isEmpty() ? paths.get(0).duration() : "未知";
        }
    }

    public record Transit(
        @JsonProperty("distance") String distance,
        @JsonProperty("duration") String duration,
        @JsonProperty("segments") List<Object> segments
    ) {}
}
```

### AmapTools.routePlan() 展示逻辑
```java
// 驾车
AmapRouteResult drivingResult = amapService.routePlan(origin, destination, "driving", destName, originCity, destCity);
if (drivingResult.route() != null && drivingResult.route().distance() != null) {
    sb.append("🚗 驾车：\n");
    sb.append("距离：").append(formatDistance(drivingResult.route().distance())).append("\n");
    sb.append("耗时：").append(formatDuration(drivingResult.route().duration())).append("\n");
    sb.append("导航链接：").append(drivingResult.navigationLink()).append("\n\n");
}

// 公交
AmapRouteResult transitResult = amapService.routePlan(origin, destination, "transit", destName, originCity, destCity);
if (transitResult.route() != null && transitResult.route().transits() != null && !transitResult.route().transits().isEmpty()) {
    sb.append("🚇 公交/地铁：\n");
    sb.append("距离：").append(formatDistance(transitResult.route().distance())).append("\n");
    sb.append("耗时：").append(formatDuration(transitResult.route().duration())).append("\n");
    sb.append("导航链接：").append(transitResult.navigationLink()).append("\n\n");
}
```
