## 关键结论

1. **召回层干净了**：57/57 的 gt 都在 top-20 候选池内（此前的"8 条池外"未复现，见下方方差警示）。优化重心完全落在「把池内的正确答案提到前 5」：rerank / 保底策略 / 权重。
2. **rerank 理论上限 ≈ 100%**（池内全部可争取），实际预期以 rerank AB 实测为准。
3. **数字方差警示（重要）**：同一套配置昨日实测 strict top-5 46.4%（`realQueryLogRetrievalHitRate`，page_size=5）与今日 61.4%（page_size=20 池内前 5 判定）不同，且昨日 top-20 覆盖 85.7%（48/56）与今日 57/57 池内也不同。差异来源：① 数据集 56→57 条（新增 1 条）；② QueryAnalyzer 分析（昨日 `analyzeUncached` 3 轮 vs 今日 `analyze` 缓存）→ LLM 生成检索词（场景/风格/季节）波动 → 命中随检索词摆动。**单点测量不可信，后续所有收益判定必须用 3 轮 median（greedyStabilityRerun 口径）作为门禁。**
