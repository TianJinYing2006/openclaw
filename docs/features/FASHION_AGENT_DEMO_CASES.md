# Fashion Agent 演示用例

这些用例用于成员 F 的入口和格式化验收，可在微信里直接发送同义句触发 `consult_fashion_outfit` 工具。

| 场景 | 用户输入 | 期望输出重点 |
| --- | --- | --- |
| 海边 | 今天去海边穿什么？ | 清爽、透气、防晒，包含鞋包配饰 |
| 婚礼 | 周末参加朋友婚礼怎么穿？ | 半正式、不穿大面积纯白，包含备选风格 |
| 通勤 | 明天上班通勤穿什么比较得体？ | 舒适复穿、办公室可用，包含降温叠穿建议 |
| 约会 | 晚上约会吃饭，帮我搭一套。 | 有记忆点但不过分隆重，包含外套建议 |
| 模糊需求 | 随便推荐一套日常出门穿搭。 | 给出安全日常方案，并提示可按场景调整 |
