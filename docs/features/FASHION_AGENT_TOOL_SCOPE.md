# 微信服装 Agent 工具范围

当前微信入口不再是通用工具箱。在完整服装运行配置下，模型实际可见的工具固定为 35 个，只覆盖衣橱、穿搭推荐、试衣、图片、天气、时间和提醒。

| 能力 | 工具数量 | 用途 |
| --- | ---: | --- |
| 图片 | 6 | 生成、查看、识别、修改和回退已保存图片 |
| 天气 | 1 | 为穿搭场景查询城市当前天气 |
| 衣橱、公共 Look 与推荐 | 9 | 画像、个人衣橱查询/展示、公共搭配灵感和基于证据的聚合推荐 |
| 衣物入库草稿 | 10 | 照片识别、候选确认、抠图、标签修改、多版本草稿和正式入库 |
| 试衣模板与虚拟试衣 | 5 | 保存/切换人物模板、展示模板、提交试衣和查询试衣状态 |
| 时间与提醒 | 4 | 当前中国时间、创建/查看/取消微信定时任务 |

当前不向模型暴露：飞书、网页搜索、地图导航、文档、语音、游戏、哔哩哔哩、星座、菜谱、汇率、快递、手机/IP/QQ 查询等泛用工具。

`search_fashion_products` 也暂时下线：在真实商品橱窗、价格和库存数据完成前，公共 Look 只能作为穿搭证据，不能被当成可购买商品。

`recommend_outfits_from_wardrobe` 是唯一向模型开放的推荐入口。公共单品召回、Look 反查、同套单品聚合、
个人衣橱匹配、确定性评分、去重和效果图任务都在服务端内部完成，底层查询和打分函数不作为 Tool 暴露。

工具筛选有两层：`ToolRegistry` 采用默认拒绝策略；聊天网关只把以上能力传给模型。两层同时存在，避免某个历史 `@Tool` Bean 因误注册重新进入微信对话。
